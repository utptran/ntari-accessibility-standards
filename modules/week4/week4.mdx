* POSITION NOTE ON PRESENTATIONAL SOVEREIGNTY 

In my opinion, presentational sovereignty extends the tradition of accessibility as it
allows each user to restyle their own render by their own will. This heavily aligns with 
the tradition of web accessibility seen in CSS keyword '!important', as it overrides the
author's or agent stylesheets.

For context, each browser has their own user agent stylesheet. These sheets will contain default information
such as default focus indicator color and width. For example, this is seen in success criteron (SC) 2.4.13 Focus Appearance,
which allows the use of an author-supplied, visible focus indicator as a sufficient technique
(G195: Using an author-supplied, visible focus indicator; link opens to new page - https://www.w3.org/WAI/WCAG22/Techniques/general/G195).

The user agent stylesheet is chronologically the first stylsheet applied, which allows for
overriding of rules, since chronologically later rules gain priority.

This is seen in the CSS 'animation' property with '@keyword' frames, and in the CSS cascade algorithm.

Placing the power to change these norms is a double-edged sword, as a user's inexperience or preferences
may inherently violate the floor of WCAG level AA.

Presentational sovereignty addresses this concern as long as the user's preferences only affects self-view render,
the user's own render. The scope of change is what really matters, not if the preferences violate WCAG 2.2. AA floor,
since the author or browser agent stylesheet should already comply to this, therefore, no liability
should be held if JFA has done their side correctly.
